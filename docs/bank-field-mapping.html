XBO

Crypto Exchange Sent via Zapier Code step → /api/internal/sync-transactions
GET api.xbo.com/v1/transactions GET api.xbo.com/v1/fiat/transactions
DB Column Endpoint Raw API Field Mapping Logic Notes
id Both tx.id / ftx.id Direct Used as upsert key — re-sent transactions update mutable fields
wallet_id Both tx.currency Looked up from wallet_map config per account + currency (e.g. USDT → wallet_bp_xbo_btc_usdt) Falls back to account_prefix + '_' + currency.toLowerCase() if not in map
company_id Both — Hardcoded per account in Zap config (e.g. inputData.bp_company_id)
bank_id Both — Hardcoded per account in Zap config (e.g. inputData.bp_bank_id)
transaction_date Both tx.createdOn createdOn.split('T')[0] → YYYY-MM-DD Falls back to queryDateFrom if createdOn is missing
type Crypto tx.type Receive → 'credit' · Send → 'debit'
type Fiat ftx.type Deposit → 'credit' · Withdrawal → 'debit'
amount Both tx.executedAmount · tx.totalAmount executedAmount || totalAmount || 0 Rounded to 2 decimal places by server
currency Both tx.currency Direct (e.g. USDT, BTC, EUR, USD)
other_party Crypto tx.sourceAddress · tx.destinationAddress Receive → sourceAddress (sender's wallet) · Send → destinationAddress (recipient's wallet) sourceAddress may be absent on some Receive payloads → stored as empty string (not our own wallet)
other_party Fiat ftx.bankName · ftx.acquirerBank bankName || acquirerBank || ''
reference Crypto tx.traceId · tx.referenceId traceId || referenceId || '' XBO sends empty string for most crypto transactions — no sender name available
reference Fiat ftx.referenceId referenceId || ''
payment_scheme Crypto tx.networkCode Direct (e.g. ERC20, TRC20, BEP20)
payment_scheme Fiat ftx.paymentMethod Direct (e.g. SWIFT, SEPA)
balance_after Both — Always null XBO API does not return running balance; synced separately via sync-balances
source Both — Hardcoded: 'xbo'
synced_at Both — new Date().toISOString() at time of Zap execution

IFX (ibanq)

EMI / FX Bank Sent via Zapier Code step → /api/internal/sync-transactions
ibanq API (polled hourly by Zapier)
DB Column Raw API Field Mapping Logic Notes
id transaction.id Direct (IFX transaction ID) Upsert key
wallet_id — Mapped per account/currency in Zap config
company_id — Hardcoded per account in Zap config
bank_id — Hardcoded per account in Zap config
transaction_date transaction.bookingDate / valueDate Date portion only → YYYY-MM-DD
type transaction.creditDebitIndicator / direction CREDIT → 'credit' · DEBIT → 'debit'
amount transaction.amount Direct (absolute value — sign derived from type) Rounded to 2dp by server
currency transaction.currency Direct (e.g. USD, EUR, GBP, ILS)
other_party transaction.counterpartyName / creditorName / debtorName Counterparty name from IFX When empty, frontend uses ifxPartyFallback() — first word of reference field as display label (not stored in DB)
reference transaction.remittanceInformation / reference Direct Used as fallback display name when other_party is blank
payment_scheme transaction.paymentMethod / scheme Direct (SWIFT, SEPA, FASTER_PAYMENTS, LOCAL_TRANSFER, WIRE)
balance_after transaction.balanceAfterTransaction Direct IFX provides running balance — available in DB
source — Hardcoded: 'ifx' (server default when not specified)
synced_at — Timestamp at Zap execution time

MoneyGate

Payment Processor Sent via Zapier Code step → /api/internal/sync-transactions
DB Column Raw API Field Mapping Logic Notes
id transaction.id Direct Upsert key
wallet_id — Mapped per account in Zap config
company_id — Hardcoded per account
bank_id — Hardcoded per account
transaction_date transaction.date / createdAt Date portion → YYYY-MM-DD
type transaction.type / direction → 'credit' or 'debit'
amount transaction.amount Direct
currency transaction.currency Direct

source — Hardcoded: 'moneygate' Used to filter Fee rows: source='moneygate' AND reference='Fee'

Finsite

Israeli Banks (Leumi, Discount) Sent via Zapier Code step → /api/internal/sync-transactions
DB Column Raw API Field Mapping Logic Notes
id transaction.id Direct Upsert key
wallet_id — Mapped per bank account in Zap config
company_id — Hardcoded per account
bank_id — Hardcoded per bank (Leumi, Discount each have their own bank_id) Finsite aggregates multiple Israeli banks — each maps to a separate bank_id in our system
transaction_date transaction.date / valueDate Date portion → YYYY-MM-DD
type transaction.type / direction → 'credit' or 'debit' ILS transactions common — amounts often large due to ILS denomination
amount transaction.amount Direct (ILS for Israeli banks) USD equivalent computed at display time via exchange rate
currency transaction.currency Direct (typically ILS, USD)
other_party transaction.description / counterpartyName Counterparty / transaction description Israeli bank descriptions often in Hebrew
reference transaction.reference / externalId Direct
payment_scheme transaction.paymentType / method Direct (LOCAL_TRANSFER, WIRE, etc.)
balance_after transaction.balanceAfter Direct if available
source — Hardcoded: 'finsite' Used to group Israeli bank transactions in the source filter
synced_at — Timestamp at Zap execution time
